EXECUTIVE SUMMARY

The Food Ordering System is a modern, full-stack web application designed to streamline online food ordering, menu exploration, shopping cart management, and administrative store operations. Developed as part of the Full Stack Application Development with ReactJS program at the ICT Academy of Kerala, this project addresses the growing demand for fast, intuitive, and responsive digital food ordering solutions.

The application leverages a cutting-edge MERN stack architecture comprising React 19, Vite 8, Tailwind CSS v4, Node.js, Express.js, and MongoDB with Mongoose ODM. The client interface features single-page navigation via React Router v7, global state management with React Context API (Cart, Auth, Theme, Toast), and a responsive component design system. On the backend, a modular RESTful API provides secure authentication using JSON Web Tokens (JWT) and Bcrypt.js, role-based authorization for customers and administrators, and persistent CRUD management for foods, categories, user profiles, and order status workflows.

INTRODUCTION

In the contemporary digital service economy, online food delivery platforms have shifted from a consumer luxury to an essential everyday utility. Traditional paper menus and phone-in orders are increasingly replaced by real-time digital interfaces that offer dynamic visual menus, instant customized carts, transparent pricing, and live status updates.

The objective of this project is to construct a production-grade, full-stack food ordering platform that bridges customer convenience with store administration efficiency. Built within the context of the ICT Academy of Kerala's internship program, the project provides hands-on implementation of full-stack engineering principles, modern React 19 component patterns, asynchronous state handling, REST API design, and MongoDB database modeling.

A. User & Order Mongoose Schemas
// User Schema
{
  name: { type: String, required: true },
  email: { type: String, required: true, unique: true },
  password: { type: String, required: true },
  role: { type: String, enum: ['customer', 'admin'], default: 'customer' }
}

// Order Schema
{
  user: { type: mongoose.Schema.Types.ObjectId, ref: 'User', required: true },
  orderItems: [{ food: mongoose.Schema.Types.ObjectId, quantity: Number, price: Number }],
  totalPrice: Number,
  status: { type: String, enum: ['Pending', 'Preparing', 'Out for Delivery', 'Delivered', 'Cancelled'] }
}
